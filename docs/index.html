使用说明文档

从安装到进阶玩法，五分钟从小白到熟练。

1. 安装与首次启动

  • 下载并运行安装包（Windows），应用名为「小芽 · 桌面生活伴侣」。
  • 首次启动会引导你选择 数据存储目录：所有记录都会写入该目录下的本地数据库（SQLite），请选一个安全、常备份的位置。
  • 之后每次启动会直接恢复上次的页面、主题与模块设置，无需任何登录。
💡 开发者：仓库内 pnpm install 后运行 pnpm tauri:dev 即可本地启动；pnpm tauri:build 生成安装包。

2. 界面与标题栏

  • 顶部标题栏：左侧为应用名；中部依次是桌宠小芽、待办脉搏（今日剩余待办）、习惯进度环、专注胶囊，最右侧是快捷记录与全局搜索按钮。
  • 顶部导航：显示你勾选启用的功能模块，顺序即你在设置里拖拽排出的顺序。
  • 待办脉搏 / 习惯环：点击可直接跳转到对应模块。
  • 窗口右上角提供最小化 / 最大化 / 关闭；如设置了锁屏密码，还会出现锁屏按钮。

3. 生活 / 工作模式

  • 左上角的「🌙 生活 / 💼 工作」切换器可在两种模式间切换。
  • 每种模式 各自记忆：启用的模块集合、模块顺序之外的主题选择。
  • 例如：生活模式开全部模块配「春」主题，工作模式只留效率模块配「标准」主题，切换时两者各自还原，互不影响。

4. 功能模块装配

  • 打开「设置 → 🧩 功能模块」：勾选的模块才会出现在顶部导航（设置对当前模式生效）。
  • 卡片可以 拖拽排序：按住卡片拖到目标位置，出现竖线指示后松手；「今日」总览固定第一，不参与排序。
  • 「全选」一键启用全部模块；「恢复默认」会同时重置勾选与排序。

5. 主题与个性化

  • 「设置 → 🎨 主题外观」：11 套内置主题 + 「跟随系统」深浅色自动切换。
  • 自定义主题：以任意内置主题为基底，逐项编辑颜色与透明度，打造专属配色。
  • 动态联动：可开启昼夜 / 天气 / 季节节日联动，应用自动匹配当下氛围（天气联动需配置城市）。
  • 个性化文案：应用名称、底部文案、主页问候称呼都可以自定义。
  • 便签颜色是「每主题专属五色」，切主题时便签自动换装，始终与整体风格协调。

6. 便签玩法

  • 「便签」模块统一管理所有便签：新建、编辑、删除、换色（黄 / 蓝 / 绿 / 粉 / 紫）。
  • 内置模式：便签悬浮在所有页面之上，可拖动、右下角可拉伸大小，位置自动记忆。
  • 桌面模式：一键把便签放到系统桌面变成独立小窗，随时收回程序内；删除便签时小窗自动关闭。
  • 便签内容实时双向同步：在程序里改，桌面小窗立刻更新，反之亦然。

7. 专注与桌宠

  • 专注胶囊：点击标题栏的专注按钮，选择 15 / 25 / 45 分钟开始一轮专注，支持暂停 / 继续 / 结束；专注中会显示倒计时进度环。
  • 桌宠小芽：完成待办（+2 经验）、打卡习惯（+3 经验）会让小芽进化；点击它可以查看当前阶段与距离下次进化的经验。
  • 小芽每 8 分钟随机冒泡陪伴，不会打扰你正在进行的输入。

9. 数据与备份

  • 所有数据保存在本地数据库，不上传任何服务器。
  • 「设置 → 数据与备份」支持导出 / 导入备份包，换电脑时整包迁移即可。
  • 应用会定期生成本地快照，误删数据时可从快照找回。
💡 建议把数据存储目录放在你自己的网盘同步文件夹或定期备份的磁盘位置。

常见问题

断网能用吗？会不会偷偷上传数据？

核心功能完全离线可用，不连接任何官方服务器，也没有数据上传通道。仅「旅行」景点搜索、天气联动等可选功能在启用时才会请求网络。

电脑坏了或换电脑，数据怎么办？

在「设置 → 数据与备份」一键导出备份包，新电脑导入即可完整迁移；日常也可以把数据存储目录放进你自己的网盘同步文件夹，双保险。

桌面便签小窗关了，数据会丢吗？

不会。关闭小窗只是收起显示，便签内容仍在「便签」模块里，随时可以再放回桌面。

支持哪些系统？

当前提供 Windows 桌面版（基于 Tauri 构建，体积小、启动快）。
